# Workout Tracker CLI

Un'applicazione da riga di comando (CLI) sviluppata in Java per gestire e tracciare gli esercizi di una scheda di allenamento. Questo è un progetto personale creato per mettere in pratica i fondamenti della programmazione procedurale.

## Funzionalità
- Visualizzazione della scheda di allenamento con stato di completamento dinamico.
- Possibilità di segnare un esercizio come "completato" tramite input dell'utente.
- Interfaccia testuale a menu gestita tramite loop continuo.

## Tecnologie e Concetti Utilizzati
- **Linguaggio:** Java
- **Strutture Dati:** Array semplici, variabili primitive (int, boolean).
- **Controllo di flusso:** Cicli `while` e `for`, costrutti condizionali `if/else`.
- **Input/Output:** Classe `Scanner` per l'interazione diretta con l'utente.

## Approccio AI-Augmented
In linea con le moderne metodologie di sviluppo, questo progetto è stato realizzato utilizzando l'Intelligenza Artificiale come strumento di affiancamento. 
Ho definito la logica iniziale, i vincoli e i requisiti, per poi analizzare, testare su IntelliJ e validare riga per riga il codice procedurale, assicurandomi di padroneggiare i meccanismi di base (cicli, controlli e array) senza fare affidamento su un copia-incolla passivo.
